# Chile regions

chile-regions.json contains simplified continental ADM1 boundary paths derived from geoBoundaries gbOpen CHL ADM1 (boundary CHL-ADM1-47653553, 2020 boundaries, build 2023-12-12). Original sources: Biblioteca del Congreso Nacional de Chile / OCHA ROLAC. License: Creative Commons Attribution 3.0 IGO.

Source: https://github.com/wmgeolab/geoBoundaries/tree/main/releaseData/gbOpen/CHL/ADM1
License: https://creativecommons.org/licenses/by/3.0/igo/

Downloaded 2026-10-19; rings west of longitude -80 omitted for the continental display. Linear latitude/longitude projection and Douglas-Peucker simplification at 0.7 display units. Region identifiers mapped to REGIONS codes. This is a discovery map, not an official border representation. Attribution appears next to the map.
